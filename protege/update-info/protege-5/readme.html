Kobayashi-MaRust Reasoner

Kobayashi-MaRust (KM) is an experimental OWL 2 DL (SROIQ) reasoner written in Rust by the Bio-Ontology Research Group at KAUST. It classifies ontologies and refuses to publish an answer it cannot justify as complete.

What the plugin does

  • Adds Kobayashi-MaRust to the Reasoner menu.
  • Computes the inferred class hierarchy, equivalent classes, unsatisfiable classes and ontology consistency, over the loaded imports closure.
  • Keeps a native session, so later edits update the hierarchy incrementally.
  • Explains inferred named-class subclass relations, unsatisfiable classes and inconsistency with verified, minimal sets of source axioms, through Protégé's Explain inference button.

What it does not do

  • No inferred object or data property hierarchy.
  • No individual queries (types, property values, realization).
  • No explanations for anonymous class expressions or property and individual entailments.

Platforms

The plugin bundles the native km reasoner for Linux (x86_64, aarch64), macOS (Intel, Apple silicon) and Windows (x86_64) and unpacks it on first use. Nothing else needs to be installed. On another platform, build km yourself and set the Java option -Dkm.bin=/path/to/km.

Two builds exist: one for Protégé 5.6 and one for Protégé 6.
