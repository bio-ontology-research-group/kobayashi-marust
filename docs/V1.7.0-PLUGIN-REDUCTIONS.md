# KM v1.7.0 Protégé Plugin Reductions and Shortcuts Inventory

This document catalogs all 25 Java-side reductions and shortcuts (`R01` through `R25`) in the Kobayashi-MaRust (`km`) Protégé plugin (`protege/src/main/java/org/bioontology/kobayashimarust/protege/`). Every reduction is classified into one of two categories:

- **Class (a) - Pure rewriting**: Java constructs an equivalent query extension (or projects an ABox-conservative TBox/RBox) and the native `km` engine computes every answer.
- **Class (b) - Partial Java computation**: Java computes part of the answer from the ontology axioms or the engine's taxonomy/realization rows. Every remaining Class (b) item has a paired engine specification in `/mnt/data1/leechuck/km-work/v170/scratch/w13/engine-items/` with minimal reproducers and timings so the native engine can absorb it.

## Summary of Round 4 Generalizations and Removals

1. **Replaced Class (b) with Class (a) pure rewriting**:
   - **`ForestABoxRollup.buildObjectPropertyValues` (`R01`)**: Replaced the Java fixed-point propagation over asserted role edges and sub-property chains with native `km` `SUB` probes (`urn:km:reflprobe`, `urn:km:reflval:*`, and `urn:km:ovprobe:*`) emitted into `rolledSource`. Also generalized `ForestABoxRollup.tryBuild` to quotient individuals by `SameIndividual` equivalence classes rather than declining ontologies with `SameIndividual`.
   - **`KMReasoner.computeDifferentIndividuals` on rolled-up forest ABoxes (`R03`)**: Replaced the Java proxy-class disjointness call with a batched `ExtendedRun` testing `X_b ⊑ cA ⊓ cB` directly in `km`.
   - **`DataValues.canUseAssertedValuesOnly` (`R12`)**: Removed the Class (b) shortcut that bypassed the engine when `hasValueProperties` was disjoint from `subPropertiesAndSelf`, replacing it with a single revision-wide batched `ExtendedRun` (`all-data-values`) over `candidatesForProperty`.
   - **`KMReasoner.classAnswer` for `OWLObjectIntersectionOf` (`R16`)**: Removed the Class (b) Java loop that intersected `getInstances` sets and unioned `getSuperClasses` sets on named-class conjunctions, routing all `OWLObjectIntersectionOf` class-expression queries to `km`.
2. **Deleted redundant Class (b) code and ontology-tuned thresholds**:
   - Deleted `ForestABoxRollup.tryRealizeSeparableABox` (108 lines of Class (b) code that was 100% subsumed by `ForestABoxRollup.tryBuild` across all 98 benchmark ontologies).
   - Removed `KMReasoner.disjointByComplement` and its `nonBottomReps().length > 500` threshold.
   - Removed the `if (!hasReflexive || !hasHasValue) return null;` ontology-tuned guard in `ForestABoxRollup.tryBuildPositiveRBoxProperties` (`R05`).
   - Removed the `inds.size() > 64` threshold in `ForestABoxRollup.tryPregroundRules` (`R07`).
   - Replaced the `signature.size() <= 15` threshold in `KMReasoner.dataPropertiesNow` (`R10`) with the semantic condition `mayEntailNonToldDataSubProperty(snapshot) && !needsLiteralDataPropertyProbes(snapshot)`.
   - Replaced the `10_000L` probe-count threshold in `KMReasoner.allObjectValuesNow` (`R13`) with `activeTargetIndividuals(snapshot)`.
