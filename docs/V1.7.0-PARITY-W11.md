## 4. Goal 4: Differing cells (136 in W11 baseline -> 116 in W11 final)

All 20 convention-difference cells from W5A and the W11 baseline were eliminated:
1. **`isPrecomputed(CLASS_ASSERTIONS)` and `isPrecomputed(SAME_INDIVIDUAL)` on the 19 ontologies with 0 individuals (19 cells, 38 calls -> 0 cells, 0 calls)**:
   - On an ontology with 0 individuals, HermiT's `precomputeInferences(CLASS_ASSERTIONS)` and `precomputeInferences(SAME_INDIVIDUAL)` are no-ops (`m_isRealized` remains `false`), so HermiT returns `false` from `isPrecomputed(CLASS_ASSERTIONS)` and `isPrecomputed(SAME_INDIVIDUAL)`.

2. **`getDataPropertyValues` literal spelling on `ore_ont_14379` (1 cell, 5 calls -> 0 cells, 0 calls)**:
   - `ore_ont_14379` contains both `"4"^^xsd:integer` (in a TBox `DataHasValue` restriction) and `"4"^^xsd:int` (in `DataPropertyAssertion` axioms on 5 individuals). Both literals denote the integer 4 in the OWL 2 datatype map (`D(xsd:int) ⊂ D(xsd:integer)`).
   - `DataValues.Candidates` now canonicalizes candidate literals by mathematical value (`valueKey`) during probing and resolves each entailed value back to the literal spelling asserted for that `(individual, property)` pair (`candidates.resolve(same, p, l)`), matching HermiT on all 18 ontologies with individuals (`18/18` cells agree).
