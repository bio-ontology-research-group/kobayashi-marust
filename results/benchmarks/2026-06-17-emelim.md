# EMELIM — complementary-definer excluded-middle elimination (HT + CB)

- Date: 2026-06-17. Build: km-incr (HEAD `28597d4`), IBEX.
- Mechanism: a clausifier pair `⊤⊑A∨B` + `A⊓B⊑⊥` entails `B≡¬A`; substituting
  `B:=¬A` and dropping the two tautologous clauses is model-preserving (sound +
  complete). Removes the excluded-middle disjunction that fired/branched on every
  node. Traced from HermiT node-label dumps (HermiT folds 5303/C10-24Chain to
  7 nodes / 5 label-types size 2-6; KM built 170 / 28 / size 24-40 from ~23 `Q_`
  definers forced onto every node).
- Reporting per standing rule: passrate + MATCH + sound/complete split +
  avg AND median wall/mem.

## Verdict

Sound + complete on both paths (CB gold-clean; HT equivalence-preserving with all
apparent unsound traced to gold/engine artifacts). Gated default-off. Candidate
to enable for the final combination decision: CB `KM_EMELIM` is a strict
improvement (+2, lower mem, 0 regressions); HT `KM_HT_EMELIM` recovers the
disjunction family (+14 MATCH) and should be combined via routing (it exposes
pre-existing HT-engine breakage on 10908, so keep the sound CB result primary).
